# 🌿 Mahsoly — AI-Powered Agricultural Advisory Platform

> A suite of intelligent microservices that help farmers make smarter decisions — recommending the right **crop**, the right **fertilizer**, and detecting **plant diseases** from leaf images. Each service is explainable by design, pairing machine learning predictions with plain-language reasoning generated by Google Gemini.

---

## ✨ Features

- 🌾 **Crop Recommendation** — Predicts the most suitable crop based on soil nutrients (N, P, K), temperature, humidity, pH, and rainfall using a trained Random Forest model.
- 🧪 **Fertilizer Recommendation** — Recommends the optimal fertilizer for a given crop and soil type, with confidence scores and SHAP-based feature attribution.
- 🍃 **Plant Disease Detection** — Classifies plant leaf diseases from uploaded images using a fine-tuned VGG19 deep learning model across 38 plant/disease classes. Includes a built-in leaf detection guard to reject non-leaf images.
- 🤖 **AI Explanations** — Every prediction is accompanied by a farmer-friendly, plain-language explanation generated by Google Gemini.
- 🔁 **Gemini Multi-Model Fallback** — Automatically retries across multiple Gemini model versions if one hits a rate limit or fails.
- 🐳 **Docker-Ready** — All three services ship with a `Dockerfile` pre-configured for deployment on Hugging Face Spaces (port `7860`).
- 📄 **Auto-generated API Docs** — Each FastAPI service exposes interactive Swagger UI at `/docs`.

## 🚀 Running Locally

Each service is a standalone FastAPI application. Follow the steps below for whichever service you want to run.

### Prerequisites

- Python 3.11+
- `pip`
- A valid **Google Gemini API key** (required for Crop & Fertilizer services)

---

### 1 · Crop Recommendation

```bash
cd Crop_Recommendation

# Install dependencies
pip install -r requirements.txt

# Set your API key
echo "GEMINI_API_KEY=your_key_here" > .env

# Start the server
uvicorn app:app --host 0.0.0.0 --port 8000 --reload
```

API docs: [http://localhost:8000/docs](http://localhost:8000/docs)

---

### 2 · Fertilizer Recommendation

```bash
cd Fertilizer_Recommendation

# Install dependencies
pip install -r requirements.txt

# Set your API key
echo "GEMINI_API_KEY=your_key_here" > .env

# Start the server
uvicorn app:app --host 0.0.0.0 --port 8001 --reload
```

API docs: [http://localhost:8001/docs](http://localhost:8001/docs)

---

### 3 · Plant Disease Detection (VGG19)

```bash
cd vgg19

# Install dependencies
pip install -r requirements.txt

# Start the server
uvicorn main:app --host 0.0.0.0 --port 8002 --reload
```

> **Note:** The `vgg19_rgb_model.pth` weights file (~533 MB) must be present in the `vgg19/` directory before starting the server.

API docs: [http://localhost:8002/docs](http://localhost:8002/docs)

## 📡 API Endpoints

### Crop Recommendation Service

#### `GET /`
Health check.

**Response:**
```json
{
  "message": "Crop Recommendation API is running. Visit /docs for the interactive UI."
}
```

---

#### `POST /predict`
Predict the best crop for given soil and environmental conditions.

**Request Body:**
```json
{
  "N": 90,
  "P": 42,
  "K": 43,
  "temperature": 20.8,
  "humidity": 82.0,
  "ph": 6.5,
  "rainfall": 202.9
}
```

| Field | Type | Description |
|---|---|---|
| `N` | float ≥ 0 | Nitrogen content in soil |
| `P` | float ≥ 0 | Phosphorus content in soil |
| `K` | float ≥ 0 | Potassium content in soil |
| `temperature` | float | Temperature in °C |
| `humidity` | float (0–100) | Relative humidity in % |
| `ph` | float (0–14) | Soil pH value |
| `rainfall` | float ≥ 0 | Rainfall in mm |

**Response:**
```json
{
  "recommended_crop": "rice",
  "explanation": "Rice is a great fit for your field right now! Your soil has plenty of nitrogen, which rice loves to grow lush and tall. The high humidity and rainfall mean your field stays moist — exactly what rice needs to thrive. The warm temperature is also a perfect match, helping the plants grow strong and produce a good harvest."
}
```

#### `POST /predict`
Predict the best fertilizer and return a plain-language explanation.

**Request Body:**
```json
{
  "Temparature": 26.0,
  "Humidity": 52.0,
  "Moisture": 38.0,
  "Soil Type": "Loamy",
  "Crop Type": "Wheat",
  "Nitrogen": 37.0,
  "Potassium": 0.0,
  "Phosphorous": 0.0
}
```

| Field | Type | Description |
|---|---|---|
| `Temparature` | float ≥ 0 | Air/soil temperature in °C |
| `Humidity` | float ≥ 0 | Relative humidity in % |
| `Moisture` | float ≥ 0 | Soil moisture in % |
| `Soil Type` | string | One of the valid soil types (see `/categories`) |
| `Crop Type` | string | One of the valid crop types (see `/categories`) |
| `Nitrogen` | float ≥ 0 | Soil nitrogen in kg/ha |
| `Potassium` | float ≥ 0 | Soil potassium in kg/ha |
| `Phosphorous` | float ≥ 0 | Soil phosphorous in kg/ha |

**Response:**
```json
{
  "predicted_fertilizer": "Urea",
  "confidence": 0.87,
  "explanation": "Urea is the right choice for your wheat crop on loamy soil right now. Your soil is currently low on nitrogen, which is the main nutrient plants need to grow green and strong. Urea is packed with nitrogen and will quickly give your crop what it's missing. Apply it evenly across your field and water it in well so the nutrients reach the roots."
}
```

#### `GET /`
Health check.

```json
  "message": "Plant Disease API"
}
```

---

#### `POST /predict`
Upload a plant leaf image to detect disease. Accepts `multipart/form-data`.

**Request:** Form field `file` — an image file (JPEG, PNG, etc.)

**Response (disease detected):**
```json
{
  "prediction": "Tomato Early blight",
  "confidence": 0.9423
}
```

**Response (no leaf detected):**
```json
{
  "message": "No leaf detected. Please upload a clear plant leaf image.",
  "tips": [
    "Make sure the leaf is clearly visible",
    "Avoid complex backgrounds",
    "Ensure good lighting"
  ]
}
```

The model classifies images across **38 plant/disease classes** covering: Apple, Blueberry, Cherry, Corn, Grape, Orange, Peach, Pepper, Potato, Raspberry, Soybean, Squash, Strawberry, and Tomato.

## 🤖 AI Explanation Feature & Gemini Multi-Model Fallback

The **Crop Recommendation** and **Fertilizer Recommendation** services include an AI-powered explanation layer that translates ML predictions into plain, farmer-friendly language.

### How It Works

1. The ML model makes a prediction (e.g., "Urea" or "Rice").
2. SHAP values are computed to identify the top features that drove the prediction.
3. A structured prompt is sent to the Google Gemini API, asking it to explain the recommendation in simple terms — no jargon, no numbers, just practical advice a farmer can understand.

### Multi-Model Fallback Chain

To ensure high availability, both services implement an automatic fallback strategy across multiple Gemini model versions:

```
gemini-2.5-flash  →  gemini-2.0-flash  →  gemini-1.5-flash
```

If a model returns a rate-limit error (`429`), a server error (`5xx`), or any other failure, the service automatically retries with the next model in the chain — with no interruption to the user experience.

If all models are exhausted, the Fertilizer service falls back to a deterministic, rule-based local explanation built from the SHAP feature contributions, so the user always receives a meaningful response.
